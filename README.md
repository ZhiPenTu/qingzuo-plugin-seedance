# Seedance 视频生成插件 (@commerce/plugin-seedance)

轻作官方独立插件，基于火山方舟 **Seedance 2.5** 新一代视频生成模型，为电商与创作者提供高质量短视频生成体验。

## 功能特性

- **文生视频**：输入细腻的镜头运镜与场景提示词，直接生成带动态音画的连贯视频。
- **首帧图生视频**：上传单张商品图或人物图作为首帧起始帧，精准延续画风生成动态镜头。
- **参数控制**：支持自适应 (adaptive)、16:9、9:16、1:1、4:3、3:4 等多种画面比例，支持 5 秒 / 10 秒时长及 720p / 1080p 分辨率。
- **凭据隔离**：火山方舟 API Key 安全保存在宿主凭据库，避免明文泄露。
- **离线安全**：基于轻作沙箱环境与受控网络通道，支持生成视频在线播放与导出保存。

## 开发与打包

```sh
npm install --ignore-scripts
npm test
npm run pack
```

打包生成的 `.ecplugin` 文件可在轻作桌面端的「插件管理」中直接导入使用。
